# Control de Célula Robótica (Pick & Place) con Codesys

Este repositorio contiene la programación y simulación de un sistema de clasificación y paletizado industrial. 

### 🛠️ Tecnologías utilizadas
* **Entorno de programación:** Codesys
* **Lenguaje PLC:** Texto Estructurado (ST)
* **Simulación:** Factory I/O

### ⚙️ Descripción del funcionamiento
El programa controla un robot tipo servo de 3 ejes que recibe palés y cajas desde diferentes cintas transportadoras. El sistema gestiona:
* Posicionamiento en ejes X, Y, Z mediante la lectura y escritura de señales analógicas de 0 a 10V.
* Activación de actuadores neumáticos para la herramienta de agarre.
* Lógica secuencial para asegurar el correcto paletizado de las cajas.
